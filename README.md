## FAQ

### What is XCutors?

XCutors is a curated collection of popular Windows-based Roblox script executors bundled together with a universal loader. It lets you choose from Volt, Synapse Z, Potassium, and Wave from a single convenient interface.

### Which Windows versions are supported?

XCutors supports Windows 10 (version 1903 and later) and Windows 11. Both 64-bit and 32-bit editions are supported, though 64-bit is recommended for best performance.

### Do I need to disable my anticomponent?

Many anticomponent programs flag script executors as potentially unwanted software because of how they interact with other processes. You may need to add the XCutors folder to your anticomponent exclusion list. Always download from this official GitHub repository to ensure file integrity.

### How do I switch between executors?

Open xcutorsLoader and simply select a different executor from the dropdown menu. Each executor retains its own configuration and script history independently.

### What scripting languages and APIs are supported?

All included executors support Lua 5.1 with extended Roblox API access, including drawing libraries, file system hooks, HTTP requests, and custom DLL integration for advanced users.

### Why does the executor stop working after a Roblox update?

Roblox frequently updates its client, which can change memory offsets and internal structures. When this happens, the executor developers release patches. Use the built-in update checker in xcutorsLoader to download the latest compatible versions.

### Can I use XCutors on multiple monitors?

Yes. All included executors support multi-monitor setups. You can drag the executor window to any connected display and resize the script editor as needed.

### Where can I find scripts to use?

XCutors includes a built-in script hub with community-vetted scripts organized by game and category. You can also find scripts on community forums and paste them directly into the executor's editor.

### Is there a risk of my Roblox account being banned?

Using script executors violates the Roblox Terms of Service, and there is always a risk of account action including temporary or permanent bans. Use responsibly and understand the risks before executing scripts on any account you value.

### How do I report bugs or request features?

Open an Issue on this GitHub repository with a clear description of the bug or feature request. Include your Windows version, executor name, and steps to reproduce the problem. Pull requests are also welcome.
